## 0. 一句话

不是把 GMIS 网页搬进手机，而是**按"打开 App 那一刻要解决什么"重新组织 49 个页面的数据**。

## 1. 已锁定的决策

| 项 | 结论 | 转化为设计约束 |
| --- | --- | --- |
| 评审对象 | 无既有设计稿，从零建立 | 基线评审对象 = GMIS 原站（49 页源码 + 登录后截图）；无品牌资产可继承，标识与主色需自建（PRD 11.1 禁用校徽） |
| 目标用户 | 全体研究生（研一—博士） | 首页不固定布局，由**学期阶段**驱动切换 |
| 场景范围 | 尽可能都做 | 全量 P0 覆盖，但分两级深度（L1 深做 / L2 覆盖） |
| 视觉调性 | 清爽年轻 + 高效且美观 | 年轻化靠圆角、留白、插画、动效；不靠大面积高饱和色块 |
| 平台底座 | Flutter 双端 | 一套自建 token；iOS 借 HIG 的动效与手势，Android 借 M3 的触控面积 |

## 2. 基线评审：GMIS 原站

| # | 问题 | 对策 |
| --- | --- | --- |
| 1 | 1280 宽三栏（导航 / 学业进程时间轴 / 右栏资料） | 重排而非压缩：4 Tab + 纵向单一流；右栏信息下沉到"我的"分区 |
| 2 | 学业进程按**业务顺序**（注册→计划→选课→成绩→评教）而非**时间顺序** | 截止日升为一级信息，用倒计时承载，不用状态色块承载 |
| 3 | 学分三环分母不统一（0/40、0/18.5、0/21.5）视觉等权 | 一个主环（总学分）+ 两行细分；主环是唯一视觉焦点 |
| 4 | 状态色（绿/黄/灰）与装饰色混用 | **红只给三种事**：选课、退选、截止。其余靠字重与灰阶区分 |
| 5 | 只有"有数据"一种状态；302 直接白屏 | 每个 L1 页强制四态：空 / 骨架 / 错误可重试 / 会话过期带回跳 |

## 3. 四条设计原则

1. **每次打开只回答一个问题** — 首页第一屏回答"我现在要做什么"，不回答"我全部信息是什么"。
2. **课表是视觉锚点** — 课程色是课程的身份色，同课跨周同色，不随位置变。
3. **危险动作刺眼，日常动作安静** — 颜色是稀缺资源。
4. **数据必须能被质疑** — 每个数字带来源与"更新于"，不做无出处的汇总。

## 4. 范围分层

**L1 深做（8 屏，逐屏评审）**
登录 · 首页 · 周课表 · 课程详情 · 选课列表 · 选课详情 + 验证码 · 成绩 · 我的-培养进度

**L2 覆盖（12+ 屏，走通即可）**
考试 · 通知 · 服务宫格 · 课表设置 · 我的设置 · WebView 容器 · 空态页 · 错误态页 · 培养计划 · 已选课程/退选 · 评教入口 · 调课信息

## 5. 首页结构：学期阶段驱动

今日课程之下设一个**动态槽位**，随阶段换内容——一屏覆盖全年级，任何时刻只看到属于自己阶段的那一条。

| 阶段 | 动态槽位 |
| --- | --- |
| 学期初（0–3 周） | 注册报到 / 培养计划提交倒计时 |
| 选课期 | 选课开放剩余时间 + 去选课 |
| 常规学期 | 最紧急的 1 条待办（评教 / 调课 / 材料） |
| 期末 | 考试倒计时 + 未评教门数 |
| 毕业流程期 | 开题 / 中期 / 查重 / 学位申请节点 |

## 6. 视觉基准：WakeUp 课程表

用户选它，理由是"美观且高效、广告少"。拆开来是三条可执行的东西，和一条我们要超越的地方。

**可借鉴**

1. **打开成本 ≈ 0** — 秒进、无启动广告、安装包小、桌面小组件直接看。对应设计动作：缓存优先渲染、分区骨架、首页首屏不阻塞在网络往返上。
2. **一屏读完** — 周视图只放课程名 + 地点，不加装饰。信息密度靠排版与留白，不靠缩小字号。
3. **可自定义的是身份，不是语义** — 课程色 / 主题 / 字体交给用户；状态色（红 / 琥珀 / 中性灰）锁死，防止语义被用户改坏。

**要超越的地方**

WakeUp 只解决"看"，我们还要解决"办"。所以视觉上"待办 / 截止"必须与"课程"同级可见，不能整屏都是课程色块——否则我们只是一个更全的课表。

## 7. "高效且美观"的可验证指标

不是形容词，是验收项：

| # | 指标 | 阈值 |
| --- | --- | --- |
| 1 | 首屏视觉层级 | ≤ 3 层（一眼扫完） |
| 2 | 冷启动到内容可读 | < 2s（缓存优先，骨架分区渲染） |
| 3 | 主路径步数 | 看今天课 ≤ 1 步；选一门课 ≤ 4 步（列表→详情→验证码→成功） |
| 4 | 单屏色相数 | ≤ 3（课程身份色不计入） |
| 5 | 字号 / 字重档位 | 字号 6 档、字重 3 档（400 / 600 / 700） |

## 8. 色彩约束（S3 展开）

- 主色走**青蓝系**——避开红 / 橙 / 绿，它们已被截止、进行中、达成三种语义占用。
- 语义色固定三枚：红 = 危险与截止；琥珀 = 进行中；中性灰 = 未开始 / 已完成。
- 课程身份色单独一套 8–12 枚，低饱和高识别度，允许用户改。
