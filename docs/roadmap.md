# 路线图与限制

## 当前版本

- 版本：`1.6.0+7`
- 平台：Android 主线；iOS 共用 Flutter 代码但尚未出包
- 信息架构：5 Tab（首页 / 课表 / 学业 / 服务 / 我的）
- 服务入口：49 项，全原生扁平目录
- 登录：网页版 VPN → 原生统一身份认证（含短信二次认证）→ GMIS 验证码
- 数据：真实 GMIS 接口；本机快照缓存 + 系统安全存储会话
- 选课：可提交/退课（二次确认 + 选课验证码）

## 已上线

- 5 Tab 全原生界面
- 49 项服务目录、服务搜索与分组筛选
- 真实 GMIS 登录、验证码、RSA 密码加密、302 会话过期重登
- 原生统一身份认证、短信二次认证、WebVPN Cookie
- 课表周视图、课程详情、提醒、ICS
- 成绩、评教、考试、调课、通知、申请、培养进度
- 课程目录、已选课程、选课/退课
- 快照缓存、会话恢复、刷新学校数据、退出登录

## 下一步

1. **真机完整回归**：在 Android 手机上重新走真实账号登录、刷新、退出、会话过期重登；确认不同网络（校园网 / 移动数据 / 网页版 VPN）表现一致。
2. **复杂服务补全**：新生入学登记、录取复查、照片核对、学年鉴定等动态表单、附件上传和打印类页面。
3. **后台提醒**：接入 `flutter_local_notifications`，补权限申请、通知设置页和免打扰规则。
4. **深色模式**：按设计稿跟随系统；当前界面固定浅色。
5. **发布工程**：正式 release 签名、iOS 包、应用图标与商店素材、隐私政策/服务条款正式文本。

## 已知限制

- 后台提醒尚未接入系统通知；当前只有打开应用时的前台提示，22:00–07:00 不提示。
- 深色模式仍为浅色。
- 部分复杂服务入口仍是只读/占位页。
- release APK 仍使用模板 debug 签名，正式分发前必须更换。
- iOS 尚未在 macOS/Xcode 上打包。
- 学校接口可能改版；页面结构、字段和认证流程需要持续回归。
- 化研助手不是学校官方产品；接口授权、正式上架和合规文本需另行确认。
