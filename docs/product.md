# 产品说明

## 一句话

化研助手是北京化工大学研究生管理系统的移动增强层：把分散在 PC 网页里的课表、成绩、培养进度和 49 项办事入口，整理成一部手机上的 5 Tab 应用。

它不是学校官方系统，也不替代学校系统。所有学业数据仍以 GMIS 为准；化研助手负责把「每天要看的东西」变得更快、更清楚。

## 给谁用

- 北京化工大学的在读研究生
- 每天需要看课表、查成绩、走培养流程的人
- 希望在手机上完成常用操作，而不是每次打开电脑找入口的人

## 用户问题

| 现在的麻烦 | 化研助手的做法 |
| --- | --- |
| 课表在 PC 网页里，手机上要放大、拖动 | 首页直接显示今天课程；课表周视图、左右滑换周 |
| 成绩、评教、考试、申请散落在不同菜单 | 学业页集中展示，服务页扁平列出 49 项入口 |
| 办事入口层级深，找起来靠记忆 | 服务页搜索 + 分组筛选，全部应用内直达 |
| 校外访问要先开网页版 VPN，再登录两次 | 原生统一身份认证 + 短信二次认证，登录后自动进入 GMIS |
| 每次打开都要重新登录 | 会话存系统安全存储，快照缓存本机；有会话时快速恢复 |

## 核心体验

### 1. 一屏看懂今天

首页把「现在该干什么」放在最前面：当前教学周、今日课程、下一节课、评教提醒、培养进度学分。打开应用先看首页，不需要先找菜单。

### 2. 课表是一张真正的手机课表

- 周视图、左右滑动或箭头换周
- 周日无课自动隐藏
- 长课名按格子宽度折行，教室信息不丢
- 课程块点开详情，详情里可以开关提醒、分享 ICS

### 3. 49 项服务，一个入口

服务页不再按「部门 / 系统」绕路，而是扁平目录：

- 个人管理、培养管理、研工管理、科研管理、毕业与学位、网上考试
- 搜索服务名
- 分组筛选
- 通知公告等常用入口直接进原生列表

### 4. 真实数据，不是演示占位

默认通过学校网页版 VPN 访问：

1. 原生统一身份认证（学号 + 密码；学校要求时输入短信验证码）
2. 换取 `wengine_vpn_ticket`
3. 进入 GMIS 验证码登录；统一身份认证输入的学号/密码只在内存中预填，用户只补图形验证码
4. 从学校接口读取真实课表、已选课、成绩、评教、通知、考试、申请和服务菜单

密码只用于当次登录，不写入偏好、快照或日志。登录 Cookie 存在系统安全存储。

### 5. 选课可以直接完成

选课页面支持筛选、余量/冲突提示、二次确认和独立选课验证码。提交成功后刷新课表与学分。提交前会明确提示「会直接写入学校系统，不能撤回」。

```text
引导

       └─ GMIS 验证码登录
            └─ 5 Tab
                 ├─ 首页：问候 / 教学周 / 今日课程 / 快捷入口 / 评教 / 学分
                 ├─ 课表：周视图 / 课程详情 / 提醒 / ICS
                 ├─ 学业：培养进度 / 成绩 / 已修课程 / 评教 / 考试与调课 / 申请
                 ├─ 服务：49 项服务目录 + 搜索 + 分组筛选
                 └─ 我的：个人资料 / 培养进度 / 申请 / 成绩单 / 设置
```

## 产品原则

- **先看结论，再看明细**：首页先回答「今天有什么」，详情页再展开字段。
- **能用原生就不跳浏览器**：业务页面全部原生；WebView 只保留为 WebVPN 认证页的兜底。
- **真实数据优先**：演示快照只用于测试、截图和旧演示路径，默认启动走真实接口。
- **不碰敏感数据**：密码、Cookie、验证码、证件号、电话、住址、邮箱不进入代码、快照、文档或提交。
- **失败说清楚**：网络、会话过期、验证码错误、选课失败都给出可操作的中文提示。

## 产品边界

- 不是学校官方产品；正式上架、接口授权和合规文本需要另行确认。
- 不保存学校密码；不代替学校系统做业务审批。
- 复杂表单类服务（新生入学登记、录取复查、照片核对等）仍需要逐个补原生表单或 WebView 兜底。
- 后台提醒、深色模式、正式 release 签名和 iOS 打包尚未完成，详见 [路线图](roadmap.md)。
