# 化研助手 1.6.0

> Android 测试版 · 2026-11-07

这是化研助手第一个可以日常使用的 Android 版本：真实 GMIS 登录、5 Tab 全原生界面、49 项服务入口、课表/成绩/考试/通知/培养进度，以及可以直接提交的选课流程。

## 这版有什么

- **真实 GMIS 登录**：默认通过学校网页版 VPN 访问，原生统一身份认证，支持短信二次认证，再进入 GMIS 验证码登录。
- **5 Tab 工作台**：首页 / 课表 / 学业 / 服务 / 我的。
- **49 项服务入口**：个人管理、培养管理、研工管理、科研管理、毕业与学位、网上考试；支持搜索和分组筛选，全部应用内打开。
- **真实数据**：课表、已选课程、成绩、评教、考试与调课、通知、申请、培养进度都从学校接口读取。
- **原生选课**：筛选、余量/冲突提示、二次确认、选课验证码、提交/退课，成功后刷新课表与学分。
- **会话与缓存**：登录 Cookie 存系统安全存储，快照缓存本机；重启应用可恢复登录状态。
- **全原生业务页面**：不跳系统浏览器；仅 WebVPN 认证页保留 WebView 兜底，默认流程不进入。

## 安装

- 下载下方 `huayan-1.6.0.apk`。
- 支持 Android 8.0 及以上（minSdk 24）。
- 如果手机里已有旧版本，请先卸载再安装（新旧包签名不同，直接覆盖会失败；卸载会清除本机偏好和缓存）。
- 本版仍是**测试版**，使用 Android debug 签名，仅用于体验和内部测试，不要用于正式分发。

## 登录

1. 首次打开先看引导页，跳过或完成后进入网页版 VPN 登录。
2. 输入研究生学号和密码；学校要求时输入短信验证码。
3. 进入 GMIS 验证码登录页，完成登录。
4. 登录后自动加载首页、课表和服务目录。

校外默认走 `w.buct.edu.cn`。校园网内可用 `--dart-define=DIRECT_GMIS=true` 构建校内直连版本。
