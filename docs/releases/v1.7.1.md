# 化研助手 1.7.1

> Android 测试版 · 2026-11-10

这版主要解决“第一天登录正常，第二天打开拿不到数据，只能退出重登”的问题，同时把会话过期的处理路径补齐。

## 这版修了什么

- **WebVPN ticket 过期后自动静默续签**：原生统一身份认证成功后会安全留存 SSO 会话（TGC/SESSION）。下次启动或使用中 ticket 失效时，应用先用它换一张新 ticket，再继续原来的流程；只有 SSO 会话本身也过期，才回到统一身份认证登录页。
- **不再卡在缓存**：GMIS 会话失效时，学校 JSON 接口可能返回 HTTP 200 + `{}`。旧逻辑会把它当成“学校没有返回学期列表”，停在离线缓存；现在会识别成会话过期，直接进入 GMIS 登录。
- **启动顺序更明确**：有效 ticket 直接复用；ticket 过期先静默续签；续签被拒才清 ticket、回 SSO；网络异常保留 ticket 和 SSO 会话，按离线处理。
- **退出清理更彻底**：退出登录会同时清除 WebVPN ticket、SSO 会话、GMIS 会话、缓存和 WebView Cookie。

## 隐私与安全

- SSO 会话只写入系统安全存储（`flutter_secure_storage`），不写普通偏好、不写日志、不进入仓库。
- 本地最多保留 30 天；续签被拒或退出登录会立即删除。
- 密码仍然不落盘：GMIS 会话过期后，仍需要重新输入密码和验证码。

## 安装

- 下载下方 `huayan-1.7.1.apk`。
- 支持 Android 8.0 及以上（minSdk 24）。
- 覆盖安装即可；如果系统提示签名不同，需要先卸载旧版（会清本机缓存）。
- 本版仍是**测试版**，使用 Android debug 签名，仅用于体验和内部测试，不要用于正式分发。

## 验证情况

- `flutter analyze`：无问题
- `flutter test`：102 个用例全部通过
- `flutter build apk --release`：成功，versionName `1.7.1` / versionCode `9`，约 60.0 MB
- 真实账号模拟器验证：破坏本地 ticket 后启动，日志确认 `got session`，应用直接进入 GMIS 登录页，没有回 SSO；清空 SSO 会话后再破坏 ticket，正确回到统一身份认证登录页。
- GMIS 会话失效（强制服务端登出）时，只回 GMIS 登录页，不弹 SSO；补密码 + 验证码后回到首页。

## 已知限制

- GMIS 会话过期后仍需输入 GMIS 密码 + 图形验证码，应用不保存密码。
- WebView 兜底登录暂不保存 SSO 会话，因此不会参与静默续签；原生 SSO 路径支持。
- 服务端 GMIS 自然超时和 WebVPN ticket 自然过期仍未等待触发，已用强制失效覆盖路径。
- release 仍是 debug 签名，正式分发前需要更换正式密钥。
