## 使用规则

- 主标题优先使用“研究生生活 / 一个 App / 就够了”。
- 不要新增“官方”“学校认证”“保证抢到”“全网最全”等表述。
- 不要在海报上展示真实姓名、学号、手机号、验证码、二维码、Cookie。
- 版本号仅在本次发布使用 `v1.7.0`；下一次发版时替换。
- GitHub 地址保持全小写，不要加 `https://` 前缀也可以，便于排版。
