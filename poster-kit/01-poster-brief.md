# 海报 Brief · 化研助手

## 1. 一句话

给北化研究生的第二块屏幕：课表、成绩、培养进度、49 项服务，以及学术报告和劳动实践的自动监测与报名，全部装进一个 App。

## 2. 使用场景

- GitHub Release 配套图、README 首图
- 朋友圈 / 小红书 / 微信群转发
- 公众号文章头图或文末卡片
- 校园社群招新、内测邀请

## 3. 画幅与输出

| 项目 | 规格 |
| --- | --- |
| 主版本 | 竖版 3:4，`1080 × 1440 px` |
| 高清版 | `2160 × 2880 px`（2×） |
| 备用版本 | 竖版 9:16，`1080 × 1920 px` |
| 格式 | PNG，sRGB |
| 安全区 | 四周至少 64 px |
| 观看距离 | 手机屏幕一屏可读，缩略图也能看清标题 |

## 4. 目标受众

- 北京化工大学研究生新生：第一次接触 GMIS，不知道服务入口在哪。
- 在校研究生：每学期被课表、成绩、培养进度、评教、活动报名分散在多个页面困扰。
- 需要抢学术报告/劳动实践名额的学生：最怕错过报名时间和名额变化。

## 5. 核心信息层级

1. **品牌**：化研助手 + 品牌标志（左上角）
2. **主标题**：研究生生活 / 一个 App / 就够了
3. **副标题**：课表 · 成绩 · 培养进度 · 49 项服务；真实 GMIS 数据，一部手机全搞定
4. **产品证据**：2–3 张真实手机截图（首页、课表、服务目录）
5. **三条能力**：真实 GMIS 数据 / 49 项服务 / 自动提醒
6. **行动信息**：Android 测试版 v1.7.0 + GitHub 链接
7. **免责声明**：不是学校官方产品，学业数据以 GMIS 为准

## 6. 版式方向

### 整体气质

编辑设计（editorial）+ 轻科技，不要“AI 生成感”的紫色渐变、玻璃拟态和霓虹光。像一张认真排过版的产品发布海报：暖白纸张、钴蓝强调色、细线、留白、克制的阴影。

### 构图

- 左侧 55% 是文字区：品牌、主标题、副标题、三条能力。
- 右侧 45% 是手机截图区：一台主手机（首页）在前，一台课表在后，形成叠放层次；服务目录可作为第三台小手机或右下角的“49 项服务”卡片。
- 左上角放 logo；右上角放 `ANDROID · 1.7.0` 小字。
- 中部可用一个很大的半透明数字 `49` 作为背景图形，但不要压过标题。
- 底部是一条深色下载条，放版本与 GitHub 地址。
- 页脚一行免责声明，字号要小。

### 建议网格

- 画布：1080 × 1440
- 左右边距：72 px
- 顶部品牌区：0–170 px
- 标题区：220–760 px
- 截图区：约 210–1230 px，右侧
- 能力区：1030–1190 px，三列
- 下载条：1230–1322 px
- 页脚：1360–1400 px

## 7. 字体

- 中文标题：PingFang SC Semibold / Noto Sans SC Bold
- 中文正文：PingFang SC Regular / Noto Sans SC Regular
- 英文与数字：Inter / SF Pro / Helvetica Neue
- 标题字重 600–700；正文 400；不要使用书法体、手写体或超细字重。
- 标题尽量 2–3 行，单行不超过 7 个汉字。

## 9. 素材使用

- **logo-1024.png**：左上角，约 72×72 px；保持原比例，不要换色、不要加发光。
- **screen-home.png**：主手机屏幕，必须保留学期、评教、学分等内容；不要出现真实姓名（原图已裁掉顶部）。
- **screen-timetable.jpg**：后方手机，可以轻微旋转 -6°～-8°，不要遮挡主手机。
- **screen-services.jpg**：可做第三台手机或右下角小卡片，突出“49 项服务”。
- **screen-webvpn.jpg**：可选，仅在需要强调“统一身份认证”时使用；不要展示输入框中的任何个人信息。

## 10. 必须避免

- 不要重绘截图里的 UI、伪造数据或添加不存在的功能。
- 不要使用真实姓名、学号、手机号、验证码、二维码、Cookie。
- 不要出现“官方”“学校认证”“保证抢到”等误导性表述。
- 不要用 3D 玻璃手机、漂浮芯片、机器人、宇宙背景、霓虹光晕。
- 不要让模型生成大段英文；英文只保留 GitHub 地址和版本号。
- 不要超过 3 台手机，不要堆满图标。

## 11. 验收标准

- 手机屏幕缩略图状态下能读出“研究生生活 / 一个 App / 就够了”。
- 三张截图清晰可辨，至少能看出首页、课表、服务目录的差异。
- 画面没有错别字、乱码、重复文字或截断文字。
- 颜色不超过 5 个主色；蓝色只做强调。
- 底部版本、GitHub 地址、免责声明齐全。
