# 调研资料

这个目录保存产品调研和接口调研资料，不是运行时代码。

- [`competitor_analysis.md`](competitor_analysis.md)：竞品与产品机会分析。
- [`feature_api_matrix.md`](feature_api_matrix.md)：49 个 GMIS 页面与接口、优先级、原生/WebView 方案对照。
- [`crawler/`](crawler/)：早期浏览器抓取/登录页调试脚本和 HTML 片段，仅作研究记录。
- [`scraped/`](scraped/)：抓取下来的 GMIS 页面 HTML，用于接口还原。

原始抓取文件可能包含登录页结构，但不应包含可用账号、Cookie 或验证码；如发现敏感内容请删除，不要提交。
